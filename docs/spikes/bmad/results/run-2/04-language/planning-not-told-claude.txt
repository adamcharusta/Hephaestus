| ## Intent
| 
| **Problem:** The shop keeper cannot see which items are running low, so reorders happen late. Story 1.2 of Epic 1 asks for a list of such items.
| 
| **Approach:** Add `Inventory.low_stock(threshold)` that returns, sorted alphabetically, the names of items whose quantity is at or below `threshold`. Items at quantity 0 are included. Build on the existing `Inventory` state; use the standard library only.
| 
| ## Boundaries & Constraints
| 
| **Always:** Items with quantity 0 are listed. Threshold 0 is valid and lists only items at quantity 0. Invalid thresholds raise `ValueError`. Nothing is printed or logged. Returned names are sorted with `sorted()`. The method reads state only and does not change it.
| 
| **Never:** No third-party dependency. No change to `add`, `remove`, `quantity`, or `names` behavior. No persistence, prices, or multi-shop logic (out of scope per PRD).
