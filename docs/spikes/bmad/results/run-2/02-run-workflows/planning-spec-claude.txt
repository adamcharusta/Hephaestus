| 
| ## Why
| 
| A shop keeper needs to see which items are running low so they can reorder them in time. This is a pain to solve for the shop keeper: the inventory tracks quantities but offers no way to list the items that need restocking (Epic 1 Story 1.2; issue #12).
| 
| ## Capabilities

| - **CAP-1**
|   - **intent:** The shop keeper can list the names of the items whose quantity is at or below a given threshold, sorted alphabetically.
|   - **success:** With items of quantity 1, 5 and 9, `low_stock(5)` returns the names of the items with quantity 1 and 5, sorted alphabetically.
| - **CAP-2**
|   - **intent:** An item whose quantity is 0 (still held in the inventory) is included in the list.
|   - **success:** An item whose quantity was reduced to 0 by `remove` appears in `low_stock(threshold)` for any non-negative threshold.

|   - **intent:** When no item is at or below the threshold, the shop keeper gets an empty result rather than an error.
