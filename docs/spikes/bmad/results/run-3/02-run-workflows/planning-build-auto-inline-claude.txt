| ## Intent

| **Problem:** A shop keeper cannot see which items are running low, so reorders are missed. `Inventory` has no way to list them.
| 
| **Approach:** Add `Inventory.low_stock(threshold)` to `shelf/inventory.py`. It returns the names of the items whose quantity is at or below `threshold`, sorted alphabetically, and raises `ValueError` for a negative threshold.
