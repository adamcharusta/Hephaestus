| **Problem:** The shop keeper cannot see which items are running low, so reorders happen late or not at all (Story 1.2, FR-2).
| 
| **Approach:** Add `Inventory.low_stock(threshold)` to `shelf/inventory.py`. It returns the names of items whose quantity is at or below `threshold`, sorted alphabetically, and raises `ValueError` for a negative threshold.
| 
| ## Boundaries & Constraints

| **Always:** Python standard library only. Items with quantity 0 are listed. Invalid input raises `ValueError`; nothing is printed or logged. Each acceptance criterion has a unit test in `tests/test_inventory.py`.
